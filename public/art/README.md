# Gallery images go here 🎨

Put your painting photos in **this folder** (`public/art/`). The gallery and
home page automatically use them — no code changes needed. Until a file exists,
a gradient placeholder is shown in its place.

## Filenames the site is looking for

Use these exact names (all lowercase, `.jpg`). If your photo is a `.png` or
`.jpeg`, either rename it to `.jpg` or tell me and I'll update `lib/config.js`.

|---|---|
| Lola | `lola.jpg` |
| The Lost Duck | `the-lost-duck.jpg` |
| Gingham Dog | `gingham-dog.jpg` |
| Malcolm the Cheese Lover | `malcolm-the-cheese-lover.jpg` |

## Easiest way to upload (no coding)

1. On GitHub, open this folder: **`public/art`**
2. Click **Add file → Upload files**
3. Drag in your photos (rename them to match the list above first)
4. Make sure the branch is **`claude/festive-noether-7y3g0t`**, then **Commit changes**

That's it — the placeholders will be replaced with your real art.

> Tip: the titles, sizes, and which file maps to which painting all live in
> `lib/config.js` under `gallery`.
